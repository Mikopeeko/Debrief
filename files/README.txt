WoW Log Analyzer
================

Your own logs:
  Double-click WoW-Log-Analyzer.html and drop in your WoWCombatLog.txt.

Warcraft Logs reports:
  1. On warcraftlogs.com: account settings > API clients > create a client
     (any name; redirect URL can be http://localhost:8765). Copy its client ID and secret.
  2. Double-click start.bat. A black window opens and the app opens in your browser
     at http://localhost:8765. Keep the black window open while you use it.
  3. Click "Warcraft Logs", paste the client ID, secret and a public report link, then Load report.

Keep these files together in one folder:
  WoW-Log-Analyzer.html, start.bat, server.ps1
