Things I'd do whichever you pick

  • Swap the order of the pull switch to Pull #32 | All pulls, so the one you're on usually comes first.
  • Make the wipe filter a small note, not underlined text that looks like a button.
  • All controls the same height (34 pixels), same corners and same gold underline when picked.
  • The boxes at the top go (your note): this section shows facts, not scores. The view name loses its number too ("5% wasted").
