# Shadow Priest (ranged DPS)

Read Oct 19 2026. Wowhead + Icy Veins (12.1.5). No Shadow change in 12.1.5 or the Oct 23/26/27 hotfixes (audit, Oct 28).
Season 2 (Wowhead): Void Volley#1242173 has **charges instead of a cooldown**; Ancient Madness#1231346 adds haste and more Voidform extension; Improved Voidform#341240 adds Void Volley charges;
new Shadeburst#73510 (apparitions cleave) replaces Phantom Menace.

## The spec in one line
Keep Vampiric Touch#34914 + Shadow Word: Pain#589 up (Tentacle Slam#1227280 applies Vampiric Touch to 6), spend Insanity on **Shadow Word: Madness#335467** to keep it up without capping (100, 150 with Voidtouched#407430),
Mind Blast#8092 / Void Volley / Tentacle Slam so no charges are lost, and line up Voidform#228260 + Power Infusion#10060 (2 min) for burst. Mind Flay#15407 filler (clip it).
Weak single target, great spread cleave and priority damage. Slow, no movement tools.

## Hero trees
- **Archon**: Halo#120644 empowers Voidform; Mind Flay: Insanity#391403. Wowhead: "significantly better than Voidweaver in all content". Icy Veins: Archon raid default (recommended), Voidweaver for M+ and Delves.
  Halo ramps slowly (Power Surge#453109, Energy Conservation, Divine Halo) → cast early in each burst; it drifts later into Voidform over a fight (normal). Incessant Screams extra stop in M+.
- **Voidweaver**: Void Torrent#263165 (3 s channel, haste adds ticks, fixed Insanity) opens Entropic Rift#447444 → Mind Blast becomes Void Blast#450405; Devour Matter (Shadow Word: Death#32379 on absorb shields).
  Better raid defense (Void Leech, Embrace the Shadow) and Torrent cast while moving (Dark Energy). Have Madness up before Torrent; can hold Torrent ≤10 s for a pack.
- Misery#238558 (Vampiric Touch applies Pain; 21 s DoTs) for most content; Invoked Nightmare#1279350 for low target counts that live long. Ancient Madness default over Improved Voidform. Mind's Eye vs Distorted Reality by Insanity generation.
  Shadow Word: Death is undertuned (Deathspeaker if forced).
- Raid (Wowhead): Idol talents for Void Apparitions#1264107 + Shadowy Apparitions#341491 talents; swap Spectral Horrors#407469 → Psychic Link#199484 on add/cleave fights.
- **Per-boss (Icy Veins, Archon)**: Sszorak pure single target (Spectral Horrors over Psychic Link); Entombed Sentinels spread 2 targets (Spectral Horrors + Idol of C'Thun, drop Descending Darkness + Crushing Void — Slam can't hit both);
  Lost Explorers 3 targets (Instilled Doubt x2 + Idol of C'Thun over Mastermind x2 + Insidious Ire); Ula'tek many low-health adds — Energy Compression over Sustained Potency (Voidform lines up with the 20 s damage amp),
  Mythic: Improved Voidform, Instilled Doubt x2, Idol of C'Thun. Without the Season 2 4-piece: avoid Descending Darkness / Crushing Void builds.
- Apex **Void Apparitions**: Idol procs spawn Shadowy Apparitions → never let Tentacle Slam cap charges, especially in cooldowns.
- Omnium Folio (Icy Veins): Unleashed Fire, Self-Mending, Lingering, Critical Power (lots of Haste/Mastery already), Overload.

## Single target — Archon (Wowhead; Icy Veins same)
Shadow Word: Pain if missing → Vampiric Touch (via Tentacle Slam or hard cast; pandemic: refresh under 30% duration, 6.3 s with Misery) → Halo → Voidform → Power Infusion →
Shadow Word: Madness if missing / about to fall off (<1 s) / near cap (deficit ≤~35) / in Voidform → Mind Blast → Mind Flay: Insanity while Madness is up → Tentacle Slam (if no more targets to DoT or movement coming; never cap charges) →
Shadow Word: Death under 20% → Void Volley → Mind Flay (clip). Moving: Tentacle Slam, Shadow Word: Death, Shadow Word: Pain.
Icy Veins: pool Insanity if Voidform is ≤25 s away; Shadow Word: Death under 20% (35% with Deathspeaker) or with a pet out.
## Single target — Voidweaver
Shadow Word: Pain → Voidform → Power Infusion → Shadow Word: Death on absorb shields → Void Blast while Madness is up or Rift is ending → Madness (missing/ending/cap/in Rift, Mind Devourer#373202) → Void Torrent →
Mind Blast → Madness → Void Volley.

## AoE
Same list. Keep DoTs on up to ~12 targets (6 from Tentacle Slam, the rest manual), skip targets that live <18 s (Pain only if ≥12 s). Funnel Madness into the priority target, or (Distorted Reality) spread it to a new target each cast.
Psychic Link: hit targets that have Madness. M+: pull with the tank and Fade threat-drop to DoT early.

## Openers
ST: Shadowform#232698 + Power Word: Fortitude → precast Vampiric Touch / **Mind Blast** (with the 4-piece, Mind Blast first — the 4-piece buff resets on combat start, so don't open with Slam) → Tentacle Slam → Shadow Word: Pain →
Halo → Void Volley → Voidform → trinkets + Potion of Recklessness → Power Infusion + racials → Void Volley → Madness → Void Torrent (Voidweaver) → priority.

## Cooldowns
- Voidform (2 min): Void Volley charges (3, +2 with Improved Voidform; use them all before it ends), full Shadow Weaving on every target, +5% (+5 Perfected Form Archon). Ancient Madness extends it per Madness cast.
  Void Volley banking for Resonant Energy (advanced); dump in Voidform, with Crushing Void 4+, or <45 s left.
- Power Infusion with Voidform; Twins of the Sun Priestess#373466 gives an ally one too (~4-5% raid DPS). Good 2-min targets: Windwalker, Flameshaper Devastation, Affliction, Sentinel Marksmanship, Devourer DH — or simply your best player.
- Trinkets: stat trinkets with Voidform/PI; damage trinkets on cooldown (Shadow damage ones inside Entropic Rift with Voidheart).
- Racials: Berserking/Fireblood/Blood Fury/Ancestral Call with PI; Arcane Torrent only pre-combat.

## Tier set (Season 2)
- 2-piece: shorter Tentacle Slam cooldown → use it more, never sit at max charges.
- 4-piece: **weave Void Volley into the normal rotation even outside Voidform** — highest priority behind not capping Insanity; open with Mind Blast, not Slam.

## Stats
- Wowhead: Int > Haste > Mastery > Crit > Vers (both trees).
- Icy Veins ranges: single target Archon Mastery 1200-1400, Crit 800-1200, Haste 1400-1600, Vers ≤400; Voidweaver Haste 1400-1800 over Crit. AoE: Haste 1600-1800, Mastery 1000-1200.
  Mastery Shadow Weaving (per DoT: Pain, Vampiric Touch, Madness). Mastery hits DR around 19%.

## Disagreements
- **Hero tree**: Wowhead says Archon is significantly better everywhere; Icy Veins suggests new players start Voidweaver and recommends Voidweaver for M+ and Delves (Archon for raid).
- Stats: Wowhead Haste first; Icy Veins single target leans Mastery with a Haste range.

## What a log can check (Icy Veins' own log checklist)
Vampiric Touch + Shadow Word: Pain uptime **99%+** on priority targets; Shadow Word: Madness uptime **90%+**; Insanity capped; Voidform / Power Infusion / Void Torrent / Halo casts vs possible and lined up;
Void Volley charges left unused when Voidform ends; Tentacle Slam and Mind Blast charges capped; PI target; movement with empty GCDs; opener order (Mind Blast before Slam with 4-piece).
