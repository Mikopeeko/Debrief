# Fury Warrior (melee DPS)

Read Oct 19 2026. Wowhead + Icy Veins (12.1.5). No 12.1.5 class changes.
Midnight removed Onslaught, Ravager, Bitter Immunity, Thunderous Roar; added Rend#772. 12.1: Rend applied passively by Whirlwind / Thunder Clap; Hack and Slash#383877 resets give the next Raging Blow a big bonus.

## The spec in one line
Everything generates Rage except **Rampage#184367** (80 Rage), which keeps **Enrage#184361** up (30-50% damage via Mastery: Unshackled Fury#76856) — the whole game is Enrage uptime. Bloodthirst#23881, Raging Blow#85288 (prioritized with Hack and Slash),
Execute#5308 (Sudden Death, stacks 2), Odyn's Fury#385059 (also Enrages); **Recklessness#1719** (Bloodbath#335096 / Crushing Blow#335097 replace Bloodthirst / Raging Blow; cheap Rampage) with Avatar#107574 (Thane) or Bladestorm#227847 (Slayer).
Delay Rampage while already Enraged to pool Rage (but cast it over 100 Rage). Whirlwind#190411 (Improved Whirlwind#12950 buff) cleaves the next attacks to 4 more targets. Never an empty GCD.

## Hero trees
- **Slayer** (Wowhead Best for raid ST and raid multitarget and M+; Icy Veins recommended for raid ST, multi-target raid and M+): Sudden Death procs, Bladestorm in Recklessness (be Enraged first — right after a fresh Rampage), Reap the Storm#444775 cleave, Unhinged auto Bloodthirsts.
- **Mountain Thane** (Wowhead Best for M+ and Delves; Icy Veins recommended M+/Delves and "constant adds" raid): Thunder Clap#6343 replaces Whirlwind (Crashing Thunder#436707), **Thunder Blast#435607** (extends Avatar, extra Lightning Strike#434969), Avatar central (Storm Surge, Avatar of the Storm).
  Recklessness + Avatar share Anger Management cooldown → macro them.
- Multitarget swap: Enraged Regeneration or Massacre#206315 → Improved Whirlwind (+ Meat Cleaver, Rampaging Ruin#1265357 for sustained adds).
- Apex **Rampaging Berserker#1269309**: Rampage gives Berserk Strength stacks; cheaper/stronger Rampage in Recklessness (~every other GCD); last point longer Recklessness + 3 stacks. Passive.
- Omnium Folio (Icy Veins): Unleashed Fire, Void-Tainted Shell, Lingering, Masterful Cunning, Echoes.

## Single target — Slayer (Wowhead)
During cooldowns: Rampage over 100 Rage → Rampage as much as possible right before Bladestorm → **Bladestorm** → Execute with Sudden Death → Rampage if Hack and Slash isn't active → Crushing Blow → Odyn's Fury → Execute → Bloodbath.
Outside: Recklessness → Rampage over 100 Rage or Enrage about to end → Odyn's Fury → Execute → Raging Blow → Rampage → Bloodthirst → Whirlwind filler. (Rend and Wrecking Throw#384110 are tiny optional gains; Wrecking Throw +500% on shields.)
## Single target — Mountain Thane (Wowhead)
During cooldowns: Rampage over 100 → Thunder Blast at 2 stacks or <2 s of Avatar left → **Bloodbath twice** (4-piece crit buff) → Crushing Blow with Hack and Slash → Bloodbath → Rampage → Thunder Blast → Crushing Blow → Execute → Thunder Clap.
Outside: Recklessness → Avatar → Raging Blow with Hack and Slash → Thunder Blast → Rampage → Bloodthirst → Raging Blow → Execute → Thunder Clap.

## AoE
Slayer: keep the Whirlwind buff up → Rampage as much as possible → Bladestorm → Execute (Sudden Death) → Odyn's Fury → Crushing Blow → Bloodbath → Execute; outside cooldowns Recklessness → Rampage → Execute → Odyn's Fury → Raging Blow → Bloodthirst → Whirlwind.
Thane: Rampage if not Enraged → Thunder Blast → Thunder Clap at 7+ targets (and whenever the Whirlwind buff is missing) → Rampage over 100 → Bloodbath → Crushing Blow → Rampage → Thunder Clap. Save cooldowns for incoming adds.

## Openers
Charge#100 → (AoE: Odyn's Fury → Whirlwind) → Recklessness (+ Avatar) → Rampage → Bladestorm (Slayer) → Rampage / Execute / Crushing Blow … (Thane: Thunder Blast, Bloodbath) → priority.
Pre-casting Recklessness is no longer needed. Stat trinkets and potion on pull with Recklessness/Lust; second potion for adds/execute. Be in Berserker Stance, Battle Shout#6673.

## Cooldowns and tips
- Recklessness on cooldown (Anger Management keeps it frequent). Don't delay cooldowns more than ~10-15% unless gaining targets.
- Fresh Meat / Odyn's Fury re-start Enrage; Cycle Charging for Rage outside Recklessness; Heroic Leap out, Charge back.

## Tier set (Season 2)
- 2-piece: Raging Blow +15%; in Recklessness Raging Blow extends it 2 s (max 6 s).
- 4-piece: Bloodthirst +10%; in Recklessness Bloodthirst adds 5% crit to it (max 10%). Slayer gets this automatically (Unhinged); Thane must use both Bloodthirst/Bloodbath and Raging Blow in each Recklessness.

## Stats
- Wowhead: Strength > Haste > Mastery > Crit > Vers.
- Icy Veins: item level > **Mastery** > Haste > Vers > Crit (Crit gives no Rage for Fury, unlike Arms).

## Disagreements
- Stat order (Wowhead Haste first, Icy Veins Mastery first; both put Crit low).
- Raid hero tree: Wowhead Slayer for all raid; Icy Veins Thane for raid fights with constant adds.
