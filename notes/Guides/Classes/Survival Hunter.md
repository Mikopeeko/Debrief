# Survival Hunter (melee DPS with pet)

Read Oct 19 2026. Wowhead + Icy Veins (12.1.5). No 12.1.5 class changes.
Season 2 (Wowhead): Flamefang Pitch#1251592 removed (Wowhead's priority still lists it — ignore); new Bombardier#1311963 (Wildfire Bomb passive), revamped Grenade Juggler#459843 (lots of cooldown reduction), Razor Edge#1253053;
Primal Surge#1272154 moved up.

## The spec in one line
"Always be Tipping": Kill Command#259489 gives 2 Tip of the Spear#260285 stacks (Primal Surge) → spend them on the next 2 abilities → Kill Command again (one every third GCD), without capping Focus or Tip.
Wildfire Bomb#259495 and Boomstick#1261193 on cooldown (Tipped), Raptor Strike#186270 (every 2nd one becomes Raptor Swipe#1259003 — must be Tipped), Takedown#1250646 with Tip.

## Hero trees
- **Sentinel for all content** (both guides): Sentinel's Mark#1253601 procs from spending Tip (never from Kill Command) → big Wildfire Bomb (bomb the marked target; one bomb can eat several marks); Takedown → Moonlight Chakram#1264949
  (one use, cast early in Takedown — it takes a while); Lunar Calling#1253852 applies a mark instantly on Takedown and raises proc chance. Don't Look Back defense. Sentinel > Pack Leader by ~2.5% (≈4% with tier).
- Pack Leader: better at 3-4 targets (equal at 5, worse beyond), Twin Fangs (the raid boss: Raptor Swipe reaches both snakes where Wildfire Bomb doesn't), priority damage/funnel; Stampede from the first Kill Command in Takedown
  (aim depends on your position vs target, not facing); worse with downtime (Lethal Barbs focus from autos).
- Builds: Survival runs AoE-build variants everywhere except pure single target (Icy Veins); swap Lethal Calibration#1262409 → Razor Edge if Boomstick reduction does nothing. Raid cleave (Wowhead):
  Two Against Many#1251718 (from Sic 'Em#1253138, −1.3% ST) for Coiled Altar, Ula'tek, Twin Fangs; Wallop → Bloody Claws#385737 with it. M+ with tier: Mongoose Rounds#1253945 over Wildfire Shells#1261229.
- Apex **Raptor Swipe**: every second Raptor Strike becomes an AoE, harder-hitting Raptor Swipe. Passive.
- Omnium Folio (Icy Veins): Unleashed Fire, Void-Tainted Shell, Lingering, Masterful Cunning, Overload.

## Single target — Sentinel (Icy Veins; Wowhead same)
Kill Command when you have no Tip left (stop generating extra right before Takedown) → **Boomstick** on cooldown → **Wildfire Bomb** if the target has Sentinel's Mark or the bomb is ≤4-6 s from 2 charges →
Takedown (with Tip; with Twin Fangs#1272139 at 0 Tip — it gives 3) → Moonlight Chakram → Raptor Swipe / Raptor Strike → Kill Command filler (prefer Takedown) → Wildfire Bomb.
Keep a Wildfire Bomb charge going into Takedown. Without Twin Fangs, **Takedown needs 2 Tip stacks** (the pet's hit lands 1 s later).
## Single target — Pack Leader (Wowhead)
Hunter's Mark → Kill Command whenever a Howl beast is ready (without wasting Tip) → one Kill Command before Takedown → spend Tip until out of Tip or Focus → Takedown → Wildfire Bomb (Tip) → Boomstick (Tip) → Raptor Swipe (Tip) →
Raptor Strike → Kill Command.

## AoE
Kill Command at 0 Tip → Boomstick (Tip; ~15 s cooldown with Lethal Calibration) → Wildfire Bomb (Tip; target marked mobs unless a bulky priority) → Takedown (swap off an already-marked target) → Moonlight Chakram → Raptor Swipe → Raptor Strike.
Position for cones: Wildfire Bomb explodes in a cone **behind the target from you** + small circle; Boomstick is a frontal cone from you (Disengage for range). Hold Bomb/Boomstick briefly if adds are about to spawn.

## Openers
ST (Icy Veins Sentinel): Hunter's Mark → Wildfire Bomb ~1 s before pull (stand far) → (Kill Command) → Raptor Strike → Raptor Swipe → Raptor Strike → Boomstick → Takedown + potion/trinket → Wildfire Bomb → Moonlight Chakram.
Pack Leader (Wowhead): pre-bomb → Harpoon#190925 + Misdirection + Light's Potential → Takedown → Raptor Strike → Kill Command → Boomstick → Bomb x2 → Kill Command → Raptor Swipe.

## Cooldowns
- Takedown (1:30, 1 min with 2 Savagery): big hit, +20% (class abilities only) and double auto speed for **8 s** — short, so prefer short on-use trinkets; Flanked#1256938 makes it AoE.
- Boomstick: 2 GCD channel; skipping it entirely is only ~2.5% ST loss → hold it for AoE when useful.
- Keep Tenacity, Ferocity (Bloodlust) and Cunning pets on your bar.
